## Reporting Security Issues

If you believe you have found a security vulnerability in Secret Terminal,
please report it to us privately. **Do not report security vulnerabilities
through public GitHub issues.**

Please email your findings to security@solvospace.com. We will investigate
all legitimate reports and do our best to quickly fix the problem.

When reporting, please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any relevant logs, screenshots, or proof-of-concept code

We ask that you give us a reasonable amount of time to investigate and
address the issue before making it public.
